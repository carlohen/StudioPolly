# Polly Designer

Sistema de agendamento do salão Polly Designer (Fortaleza). Next.js (App Router) + Supabase.

Veja [PROJETO.md](./PROJETO.md) para as regras de negócio, o banco de dados e a ordem de trabalho.

## Desenvolvimento

```bash
npm install
npm run dev       # http://localhost:3000
npm test          # testes da lógica de agenda (Vitest)
npm run build     # build de produção
```

Variáveis de ambiente em `.env.local` (não commitado) — veja a seção correspondente em `PROJETO.md`.
